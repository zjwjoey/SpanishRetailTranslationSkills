# IKEA 审核：输入形态与漏译复核

首1000条AI审核后的工程候选门禁。适用于两种审核模式；不代表人工确认或保证不存在遗漏。

1. **先确认实际输入形态。** 完整原生契约与工程紧凑中间件分开记录。后者可能使用 title_zh、specifications_zh 的有序数组，不能读取不存在的 name 后宣布“名称缺失/P0”。必须映射到实际非空字段；格式不符与语义缺失分别报告，不能把紧凑结果宣布原生契约通过。
2. 在读中文前按源字段/分句列事实；再读全部目标字段和迁移账本。声称新增前搜索完整源；声称漏译前查全部目标。不得用兄弟SKU补证。引文中不得添加省略号、改冠词或拼接不连续片段冒充精确原句；需定位真实叶路径和 occurrence。
3. 机械 hash、引文存在、行数检查与语义审核分开。手工行数或路径错误保留更正日志，不改源、不伪造审核覆盖。不能将“无发现”解释为质量100%。相同SKU+字段+根因去重，多句同一“椅套”错译不重复计数。
4. 覆盖复合声明每个条件：质保年限及手册指向、强制锚固及螺钉/墙塞/专业咨询、展开前方无人、每个另售对象、完整兼容对象及功能解释。只保留前置可选固定不代表保留强制警告；完整强制安全警告消失按质量契约评估P0，不能降成一般润色。
5. 材质逐组核对主体、部件、基材/涂层/表面及各比例。聚酰胺误氨基、泡沫床垫基材误床架、坐墩套误椅套、花架腿误椅腿须检查完整上下文；不能全局替换多义词。别名、正常意译和精度下降不自动判成材质/主体P1。
6. 不制造冲突：座位数/商品单位/物流包装层次不同，灰/深灰粒度不同；源 Potencia+mAh 是标签异常，不要求目标输出技术上错误的功率单位。保留源证据、数值单位及待核槽。真正互斥的颜色继续排除，不能为凑字段覆盖而补值。
7. 制造商地址不是商品洗护。原文只有落款而目标新增可机洗，应报告新增；明确源功能/兼容声称可按来源声称保留，未经现实验证本身不是删除理由。“未设计供儿童使用”与禁止使用的强度也须分别判断，避免升级原警告。

每条发现写可核对原句、实际中文、影响和严重度依据；不确定的字段继续局部隔离。AI相互认可和官方网页经AI读取都不自动产生 VERIFIED。候选修订后独立复查，不能只以字符串已替换宣布语义关闭。
