# TRANSLATION_AUDIT 操作规则

适用契约 `1.0.0-foundation`。后审检查译文本身，也复核前审是否误删；源审通过不是中文自动通过。

## 审查上下文

接收完整ITEM记录、前审输出或短字段skip记录、实际中文输出。先匹配item_id/product_id/source_snapshot，原始与候选的source hash不同不得沿用。只有精简后的文本而没有完整原文，无法审误删，FAILED；前审记录丢失而原文尚在时标日志缺口REVIEW_REQUIRED，可独立重建候选但不能冒充历史动作。

优先独立上下文，先看完整西语重建事实再看中文，不能先接受译者解释。independence_method记真实方法与限制：独立执行者的新上下文、或当前上下文的source-first重读；后者不能宣传为真实隔离。若没有独立重读，保持REVIEW_REQUIRED。不得请求或读取未授权的holdout答案，当前已暴露合成示例不能当正式盲测。

## 两份清单与双向证明

第一份清单从源建立：商品主体、用途/功能、材质、颜色、型号/系列/品牌、兼容对象、参数、尺寸各轴、容量与件数、否定/大约/最多/混款等限定、事实冲突及来源声称。

第二份从实际中文建立，不读翻译者自评当依据。逐项核对：

1. 输出事实全部能沿field_alignment/fact_ids回源，不能由类目或常识补材质、兼容、安全认证、销量地位。原文营销声称仍只是来源声称。
2. 每个重要源事实在translation_zh、identifiers或research_metadata中有去向，或冲突隔离有明确待核记录。标题短不代表遗漏，找完其他结构字段和对齐证据再判。
3. 保护词原串、大小写/后缀/斜杠等保持原识别形式；允许另列中文品牌候选，但不能只留未经批准别名替换标识。型号不能拆成包装数，兼容品牌不能变制造品牌。
4. 非TRANSLATE动作逐项核对保留账本。元数据、品牌及代码实际值应可读取；去重canonical必须存在、无环且保留同等事实。误删一个独有刀片数量或型号后缀即候选P0，不因前审说“重复”放过。
5. 源categories只被翻译，proposed_research_categories单列，不把建议研究分类覆盖源类别；无人工批准不得假称批准映射或术语。

## 数值、配置与局部冲突

正则只能发现候选差异。`1,5`与`1.5`可能等价；`1.000`需要地区/量纲语境；尺寸长宽高、范围和单位必须相符。2×500ml保留2件与单件500ml，不能只留1L；12L/天不等于水箱12L。主机、附件、内装件和总包装数量分别建槽，5合1不等于5件，60分钟不等于60件。

源两处同槽冲突时，核对中文冲突槽为null/待核且保留两段源证据；无证据选2或1都不是成功修复。品牌/型号/功能等独立事实不可一并null掉。主体缺失、不完整后文涉及配置或不明确变体仍待核。源问题本身不自动计为译者错误，静默猜测、漏报或错误定稿另列候选P0/P1。

## 结论、问题与修复

stage=TRANSLATION_AUDIT。review保留mode、independence_method、checked_fields、unreviewed_fields、candidate_findings和结论；每个finding含severity、field、source_span、target_span、reason，可另列修改候选。遗漏的target_span可null，但必须指出应有目标与证据；输出虚构的源依据可null，必须给完整源核查范围，不能伪造支持quote。涉及多个源字段时逐项证据。

P0：错配、主体/关键型号/配置错误、虚构或误删重要事实；P1：重要用途/属性/术语/类目误判；P2：不影响事实的表达。分歧、疑似错误为candidate_findings，不自动REJECTED或知识真值。若给出修订建议，保留本次原候选和发现，修订后的受影响事实另一次重审，不能悄悄改完原译再宣布原结果通过。

PASSED需独立重读完整源、源审日志和中文，实际请求范围已全部检查，账本闭合，无未决P0/P1/源问题；显式仅标题审查的结论限定标题，不能汇总整商品通过。部分审读却请求全商品，或存在源冲突/截断/未审字段影响判断为REVIEW_REQUIRED。缺身份/关键原文无法评审为FAILED。PASSED仅本次AI过程状态，不等于人工VERIFIED。

run_metadata如实写模型（未知unknown）、契约/Skills/知识版本、实际读取Skills、输入hash、调用方式、开始/结束/耗时/token（不可得null）。保留source/identifiers/retained_facts/field_alignment/保留账本，不把摘要取代证据。质量统计分别列商品、字段、事实原子和问题数，分母0为N/A；未经人工gold不得宣称优于普通Codex或上游。
