# IKEA 材质与部件消歧

工程候选说明，未写入 approved 术语。须依本SKU完整源和类别使用，不按下列词机械替换。

| 源词/结构 | 候选判断 | 必须排除的误判 |
| --- | --- | --- |
| Plástico amídico / polyamide | 聚酰胺塑料；检查聚合物词根 | 氨基塑料是另一类，不可混用；酰胺简称需看语境，不自动判错 |
| Plástico acetálico | 缩醛/聚甲醛语境，保留适当别名 | 不因同义译名不同判材质错误 |
| Somier + 聚氨酯泡沫，所属商品是床垫 | 床垫基材/基层候选 | 不是钢制床架；若实际是钢床架则不能改成床垫芯 |
| Funda | 由所属商品确定床垫套、坐墩套、椅套等 | 不能默认椅套；主体不足则保留候选并待核 |
| Pata / Estructura de pata | 支腿/支腿框架，具体主体明确时可柜腿、椅腿等 | 不把花架、柜子、沙发的腿统称椅腿/床腿 |
| fresno / roble + efecto | 白蜡木/橡木外观效果候选 | 树种不混用；效果不推出实木材质 |
| teñido en masa | 原液染色工艺候选 | 不是大地色；不从工艺补颜色 |
| madera blanda / corcho | 软质木材 / 软木分别理解 | 不因中文“软”字相同混淆地板材质 |

材料清单按部件和层次理解，基材、贴面、贴膜、涂层、封边不能并成同一种材料。组成比例和再生比例分开保存，不能将一个部件的比例扩展到整件商品。无法定位多部件归属时局部待核，明确材料不丢。

先比较语义槽再讨论冲突：座位数、商品单位数、运输包装件数不同；灰色和深灰色有粒度差异；容量单位 mAh 不因源标签 Potencia 就变成功率。不要以技术纠错名义静默改源，列原键值及问题。名称精度下降与主体错判分开分级，例如 Pomo 泛译拉手不必自动等同整件商品角色错误。

家具五金pomo候选“旋钮”、tirador候选“拉手”；同句出现须保留两个部件类别和“和/或”关系，不能用两个把手泛称抹掉区别。洗碗机程序列表Autolavado候选“自动洗涤”，与Mantenimiento de la máquina“机器维护”区分；源未给自清洁不可补出。比较倍数先辨总量/增量：“为4倍”与“高出4倍”通常不等价；veces más若基准未明则保留原比较对象及具体待核槽，不替源裁决，明确的es cuatro veces不可无故隔离。

“que el vidrio normal”等比较对象不等于倍率总量/增加量定义；只有veces más词组且无另外倍率定义时，候选保留原句并局部待核，不将数学口径臆断成确定中文增量。此为本轮谨慎的表达门禁，不宣称原商品声明错误。
