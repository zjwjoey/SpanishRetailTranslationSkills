# 事实槽隔离与覆盖闭合

候选流程规则，不是人工批准术语。适用于Amazon长字段，也适用于其他平台混合明确事实与疑点的字段。沿用现有契约，不引入第七种动作。

## 隔离单位

先从完整源按对象、属性、值、条件拆事实；调度用的字符分段、JSON字符串或整段description不是业务事实槽。同段“钢制提手；容量20 L；颜色甲/乙冲突”保留提手材质和容量，只隔离同一变体的颜色。不要把整个段标REVIEW_REQUIRED/null来代替细分；完整段均不可可靠解释时才允许整段隔离，并给出具体证据。

每个保留/隔离事实有唯一fact_id、source_field、精确quote及occurrence、对象/属性/限定和目标路径。quote相同多次出现须区分位置；偏移无法可靠核算时为null，不臆造。保留事实有实际中文；待核槽为null，另存原句与原因，不能把疑点原词夹在确定中文中假装解决。一个中文句子混入明确与未明属性时重写为仅含明确事实的句子，不用文本替换猜着删。

## 冲突闭合

确认同一商品/变体、对象、属性、条件、包装层次确实互斥，再建conflict_id。将它连接到全部相关事实与目标，尤其title、variant、重复规格及去重canonical；不能隔离描述中的材质，却让标题继续确定宣称同一个争议材质。传播的是受影响事实槽，不是相关整段。部件钢材和主体塑料、净重和包装重、纤维成分和织物名称不是天然冲突。缺少可选更新日期不影响已给出的商品规格。

DEDUPLICATE必须指向仍实际保留的等价事实。canonical若待核，重复处同槽也待核；其他独有事实继续保留。Ver más只处理展示提示及实际缺尾槽，完整前文不能一起删。

## 覆盖闭合

生成前保存源事实清单；生成后每条重要事实指向明确中文、标识、元数据、等价canonical或有证据的待核槽。未映射事实先补译，不只写“已检查”。独立核对：用途/人群、每个部件材料、尺寸轴、附件/总包装、兼容列表及后缀、否定、比较基准、适用条件。补充剂源声称中的均衡饮食/良好习惯条件不能省略成保证疗效；相机对焦方法和数字场景功能不能被光学倍率代替。

以完整源和所有中文目标判断遗漏；合理跨字段迁移需实际目标路径，不能仅以源文归档当已译。所有剩余疑点继续REVIEW_REQUIRED，AI自查不构成人工验收。
