# 第二轮24件新商品比较协议

状态：运行前预登记；本文件不报告运行结果。范围：Action 12件、Amazon 12件真实新商品。协议上下文只读取README、AGENTS、质量契约、首轮比较协议与首轮汇总报告，未读取Skill修改、提案、原商品、新选样或运行输出。

## 1. 比较对象与证据资格

A＝首轮1.0.1专业Skills冻结版本；B＝第二轮候选专业Skills。这里的A/B不是质量契约中的普通Codex/上游基线字母。本轮普通Codex为 `NOT_RUN`，上游方法为 `NOT_COMPARABLE`，不得冒称三方比较。

本轮是共享工作区中的开发性新商品配对观察，不是权限隔离Holdout或正式盲测；human gold数为0，dataset_split保持unassigned，不能自动赋予VERIFIED。AI判断、官网补证或用户允许继续工作都不等于人工逐事实确认。语义优劣的正式验收仍为 `BLOCKED`，可报告有证据的行为变化，不能报告正式准确率提升、生产就绪或V1通过。Learning人工确认门禁继续适用。

## 2. 冻结与样本准入

协调者在任何生成前保存冻结manifest：A/B名称、parent commit、完整加载文件/知识/公共契约清单、实际路径、逐文件SHA-256、快照路径、协议hash，以及同一任务指令与输入hash。仅Skill版本及其预登记配套参考内容改变；其他指令、契约、输入和工具条件保持一致。不得把首轮后审译文作为A或B新输入。

选样者固定24件身份、平台、源工作簿/快照、完整纯ES字段、字段hash、选择方法及类目/风险分布。排除114个旧身份及已知同款、父子变体、多快照、跨平台同款、标题近重复商品组；保存排除依据及未能核实的家族关系。无法确认是否新商品的条目不得悄悄算作独立新样本。合理品牌/型号中的外语可保留，完整非ES主体不入选。不得改写、合成源文或见到输出后换掉难例；准入失败应在生成前更换并重新冻结。

生成者只能读取各自冻结Skills、同一24件纯ES输入、稳定身份和共同任务指令；不能读历史中文、旧/新参考答案、另一臂结果、QA事实清单或评判结论。共享目录仅靠行为限制，不声称技术隔离。原始货盘永不覆盖；无需外部操作或额外付费服务。

## 3. 同条件执行与共同输出要求

A/B分别在两个新上下文、同一继承模型和设置下执行同一批24件，采用同一任务架构：Category/Terminology初判与消歧→按需SOURCE_AUDIT→Translator→相同自查。按批次使用五个既有Skills，不为每SKU固定启动五个Agent。不得只给B追加输出要求、补证或自查机会。执行前固定自查范围和attempt选择规则；任何重跑保存新attempt和原因，不以挑选最佳输出代替预定运行。

两臂任务必须显式要求以下相同字段，特别避免首轮类目要求不明确造成的24项格式缺口主导结论：

- item_id、platform、SKU/ASIN及变体、完整源引用/快照hash。
- 中文名称、有序key/value规格、中文研究描述。
- 平台原类目西语及对应中文，与建议中文研究类目分开；源类目缺失明确标缺失。
- 品牌、系列、型号、标识原串及其归属/兼容关系。
- 源审动作及实际source_field、精确quote/定位、目标字段；跳过前审说明原因。
- 真冲突、截断、不确定槽与双方源证据；明确事实继续输出，局部问题局部隔离。
- 数据问题、翻译候选状态和待独立审核状态分开，生成者不得自签PASSED/VERIFIED。

记录实际模型、可取得设置、上下文及工具方式、起止时刻、加载hash、输入/输出/唯一身份数。不可观测模型设置写 `unknown`，不能声称模型条件完全相同。Token、费用、成本、可靠耗时不可取得写null；不得按字数或预设单价估计为实测。输出完成后冻结原件及hash，再交独立QA。

## 4. 独立QA：先源事实，再读输出

未参与两臂生成的QA先仅看完整24件源文，建立并冻结共同事实清单，然后读取全部24对输出；不得从某臂引用列表反推应审事实。清单按item_id和固定语义槽记录：主体、用途、重要属性、尺寸轴/单位、包装层次、型号/品牌/兼容、类目、否定/限定条件，以及源冲突/截断/噪声。逐原子记录source_field、quote、对象/变体、单位与限定、重要性、确定性、期望保留位置或合理排除原因。源事实无法确定时保留待核，不创造中文gold。

QA须核对全部24对的完整源文、事实清单、源审账本和目标文本。精确引用有效只说明可定位，不说明完整事实覆盖；独有事实、否定、范围/上限和包装关系仍须逐项查漏。输出中新增主张也逐项回查来源。原子清单冻结后新增发现以有时间及理由的增补记录，同时对A/B重审该槽，不能只扩一臂分母。

真冲突须指向同一对象/变体、同一语义参数槽且无法同时成立的源宣称，保存双方证据。相同数字用于读速/写速、不同部件/参数、兼容清单增补、常识觉得异常，本身都不足以成立冲突；缺少官网不自动阻断源中明确宣称。可保留“源文宣称”与未验证实际性能的区别。反之，不能为减少待核标签而吞掉真正互斥配置、截断独有事实或身份不明。

## 5. 问题账本与分层计数

每个finding固定记录：item_id、arm、fact_slot、issue_key、维度、severity、source_field/quote、target_field/quote（缺失写明确的missing路径）、判断理由、影响字段、certainty及配对状态。确定性只用 `CONFIRMED_AI_FINDING`、`UNCERTAIN`、`UNRESOLVED_DISAGREEMENT`；后两者单列，不算确定错误、纠错或提升。源自身问题独立记账，不自动算译者错误。

issue_key＝item_id＋固定事实槽/对象＋错误根因。同根因在名称/规格/描述重复、跨维度展示只计一次并列全部影响字段；独立事实槽才分项。一个issue取最高严重度，不能重复算P0/P1。配对必须使用同一槽，分别标corrected、new、persistent、equivalent、uncertain；仅更换措辞不是纠错。

统计分开三层，禁止以合并总数宣传语义提升：

|层|口径|
|---|---|
|商品语义P0/P1|P0：身份/主体/关键型号、数量、尺寸或配置错误，重要属性虚构/误删；P1：重要用途、属性、术语、实质类目错误或遗漏。实际丢失事实按严重度记本层，不降成流程问题。|
|误阻断流程P2|明确事实仍在正文按源宣称保留，却被无依据加待核/多余隔离的情况。必须指明本应继续输出的明确槽及无真矛盾依据；如果事实被实际抹掉，归语义层。必要隔离不是错误，awaiting_post_audit等一般工作流状态不是阻断。|
|机械/输出及其他P2|身份/字段结构、平台类目中文缺字段、引用定位、出现次数、格式/风格分别报告。若造成实质事实错误则归语义层；同根因只计一次。本轮须单列平台类目字段合规率，不能将其改善归为商品准确性提升。|

必要待核槽、确定误阻断槽、不确定隔离槽、整件置空数分别列；生成者自报待核商品数可作描述，不作为质量指标。误阻断减少必须同时检查真冲突证据与局部隔离是否保留。

## 6. 固定分母与报告表

分别报告Action（计划N=12）、Amazon（N=12）、合计（N=24），A/B各自及配对结果。缺输出、失败、漏审不从计划分母剔除。

- 身份匹配产出覆盖率、共同输出字段完整率、逐件QA覆盖率、完整配对覆盖率：分母固定12/12/24；另列完成数及缺失原因。
- 确定P0/P1受影响商品数/固定计划N，并列实际完成语义审查数与漏审数。漏审不算无错误；有漏审不作全24件无P0/P1结论。
- 各层确定issue数、P0/P1/P2分级数；每件issue数以实际完成对应审查件数为分母，同时列固定N。该比值可大于1，不能称准确率。0分母为N/A。
- corrected/new/persistent/equivalent/uncertain按同一issue_key配对，分母为实际完整审查的配对商品数和实际可判定问题槽数，均显式列出；缺配对阻止完整比较结论。
- 事实覆盖只在共同原子清单逐项核查后报告：分母＝各平台冻结且可判定的源事实原子数；按A/B列完整保留、遗漏/错译、待核及未审数。另列未知源事实原子数和增补版本。不把重复引文次数当事实分母。
- 真冲突保留/局部隔离以QA确定的真冲突槽为共同分母，误阻断以QA逐一审查的明确可输出槽为分母；同时列绝对槽数。无槽为N/A，不能写100%。
- 人工确认数=0，人工修改率、人工准确率=N/A；不得把AI确认计为人工。普通Codex及上游未运行状态按第1节保留。

最少三张汇总表：语义P0/P1；误阻断及真冲突保护；机械/输出/其他P2。旧案例专项/跨Skill回归另表，注明旧样本和覆盖；不得与新24件相加或冒充新样本改善。报告保留未决清单与残余风险。

## 7. 验收门禁、原件与结论限制

1. 冻结hash、纯ES同输入、身份新颖性及共同任务要求无法核实，或两臂受答案污染，暂停可比性结论，补记偏差，不静默修饰为公平比较。
2. 任一新增P0、关键配置倒退或候选未处理P0立即阻止候选升级，保留回退证据；未解释P1回归同样阻止。不能用总数下降、P2减少或旧回归通过抵消。
3. 必要真冲突被静默猜定、关键待核证据丢失须按实际语义风险计错并阻止升级；不得以减少REVIEW_REQUIRED达标。其他不确定项不计改善，影响关键判断时先保持CANDIDATE/待复核。
4. 语义P0/P1均为0只表示本次已审范围未观察到确定问题，不等于准确率提升或完整无遗漏。机械/流程改善单独解释；一次小样本、随机生成、未知设置及无人工gold限制归因。正式质量门禁不因本轮完成而解除。
5. 原始A/B输入、输出、运行日志、QA事实清单、findings、统计、hash与所有attempt永久保留；后审修改另存post-review/新attempt，限定回归另报，绝不倒灌原始A/B统计。若纠正评审判断，保留初判及带理由的新判版本，不覆盖原判。
6. 交付冻结manifest、24件只读输入及选样排除证据、两臂输出/日志、全24对QA、分层配对表、旧回归表、未决与回退路径。私有源文及逐件材料留在忽略目录；本协议不授权外传、提交原始货盘、push、merge或发布。

协议修订必须保留旧hash、修订原因和相对运行/见到输出的时间；见输出后改口径属于事后分析，不能冒充本预登记。五Skill仍为候选工程成果，未经人工确认不进入approved知识或正式训练结论。
