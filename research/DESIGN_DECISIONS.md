# 设计决策记录（V3）

日期 2026-10-16。依据：用户 V3、根 README/AGENTS 与本轮固定提交上游实证审查。状态为 Foundation Candidate 的设计依据，不是已测得的翻译质量或吞吐承诺。

## D01 — 固定五个专业 Skills

清单：es-retail-category、es-retail-terminology、es-retail-reviewer、es-retail-translator、es-retail-learning。主智能体通过 AGENTS.md 管理任务依赖、文件所有权、结果汇总和风险分派，不再增加正式协调 Skill。旧 V2 “六 Skills”是已被 V3 取代的范围；先前 reports/UPSTREAM* 是历史审查，不继续作为当前五入口验收依据。

原因：技能是可被不同执行者按需使用的专业能力；协调不应额外增加商品上下文负担或与五能力分工重复。上游四角色文档流程可以参考角色边界，不能强迫每条 SKU 走固定四/五智能体流水线。

## D02 — Reviewer 同一入口、两个明确模式

SOURCE_AUDIT 负责商品片段内容去向，不最终翻译；TRANSLATION_AUDIT 重新对照完整原文、前置动作和译文检查事实、遗漏及误删。它们共享反虚构/不静默丢事实原则，但输入和输出职责不同，必须显式指定模式。

SOURCE_AUDIT 依赖 Category/Terminology 初判后的消歧结果，动作只可为 TRANSLATE/PRESERVE/METADATA/DEDUPLICATE/EXCLUDE_FROM_DESCRIPTION/REVIEW_REQUIRED。保留来源片段、动作、理由、去向和状态。后审必须看到被精简前的完整源；否则不能发现“前置误删后译文看似完整”的问题。

这是 V3 新增的零售审查机制。三个上游均未提供可直接复制、完整实现此契约的商品源筛选器；本项目必须独立创作并测试，不将上游文档结构检查冒充前置价值筛选功能。

## D03 — 事实和标识优先于内容压缩

源事实及稳定身份 > 人工批准术语/保护标识 > 去重筛选 > 中文润色。品牌、系列、型号、ASIN/GTIN、零件号和代码可原样保护并转独立字段；平台排名/评分可转元数据，不进入功能描述。两者都应保存。

重复片段必须证明没有独有事实且有保留副本；近似标题不能只凭相似度去重。Ver más 等残留还需检查是否截断。数量、配置冲突保留双方证据并 REVIEW_REQUIRED，不能选择更常见值。片段不翻译不等于丢弃原文。

## D04 — 分类与术语可并行初判，语境有依赖

Category 保留源分类，研究类目建议单列。Terminology 判断语境词义并保护品牌/型号，不替Reviewer删整段。初判可并行；最终多义词须合并类目与实际用途再定稿，前置审查不能脱离这些结论同时给最终删减意见。

Claude按original单键去重和一词一译不适合零售；采用适用/排除语境与批准版本。未知词保留候选，不虚构标准词条。

## D05 — 批次加载与风险分级，避免按商品固定多 Agent

短字段低歧义：批次执行者复用同类目知识，按需读取相关Skill；长字段/冲突/品牌型号风险：SOURCE_AUDIT后重点独立后审。所有处理记录仍做身份、字段完整、数字单位和状态的基础核对；低风险抽检不等于全量语义审查。

5,500 SKU 是目标规模，不直接承诺或执行全量。100–200 SKU试运行、普通40–60/批和长字段5–15/批仅是用户给定实验起点。并发数根据真实能力、输出稳定性与成本测量决定；没有测量就报告 NOT_RUN，不写吞吐提升百分比。

## D06 — 复用必须同时绑定源与知识版本

已有人工确认译文仅在商品/变体、源快照内容、关键属性及适用规则均未变时复用，记录依据。相同ASIN不同快照不得直接复用旧规格。变体/近重复/同款跨平台先分组再划分训练与保留集。共享工作区或Git worktree不是答案访问隔离。

Learning 只从已批准人工纠错提候选变化，不能自行覆盖正式知识和已发布版本；单例不升级全类目绝对规则。上游 confidence、历史中文和AI一致意见均不自动 VERIFIED。

## D07 — 基线、测试与发布分开

上游工程脚本可用于检查其功能边界，不能用 VALID 或 exit0代替翻译正确率。本轮工程探针确认结构通过而译文无关、game无产物仍报成功等限制；这些不是A/B/C翻译质量结果。

当前 B=NOT_COMPARABLE：Codex新内容许可未明，Claude原运行机制不兼容，game未实现。未来若运行MIT Claude的Codex适配，须单列适配条件并用相同模型/输入/评判口径记录。无可信人工样本、独立评估或自动调用证据时，候选停留Foundation Candidate，不宣传V1稳定或优于上游。

## 尚需后续证实

五 Skills 的自动发现/显式与隐式调用、误触发、双模式审查保真、真实商品语义质量、人工改动率、A/B/C同条件效果、批量性能均需对应独立证据；本轮R1不执行或推定这些结论。许可证未明内容的授权仍未获得；本轮以独立创作为工程可继续路径。
